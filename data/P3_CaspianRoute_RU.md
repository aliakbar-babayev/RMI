# P3: CaspianRoute - Платформа отслеживания автопарка и доставок

**Отрасль:** Логистика | **Спонсор:** Эльчин Мустафаев (COO, TransCaspian Logistics) | **Статус:** В работе (неделя 10 из 24)
**Сроки:** 3 авг 2026 - 31 янв 2027 | **Бюджет:** 350 000 AZN

---

## 1. Стратегия проекта
**Видение:** Единая платформа, которая в реальном времени отслеживает 220 грузовиков и 4 склада, автоматизирует документы по доставке и показывает клиентам статус отправлений онлайн.

**Цели**
1. Заменить диспетчеризацию через Excel и телефон веб-консолью диспетчера к 15 декабря 2026 года.
2. Сократить среднюю задержку доставки на 25%.
3. Интегрироваться с системой таможенных электронных деклараций для трансграничных перевозок к 31 января 2027 года.

**Стратегия:** Разработать веб-консоль диспетчера, мобильное приложение для водителей (только Android) и страницу отслеживания для клиентов. Использовать GPS-трекеры, уже установленные на грузовиках, и коммерческий API карт для маршрутизации.

**Вне рамок проекта:** Управление топливом, расчёт зарплаты водителей, приложение для iOS.

**Ключевые допущения:** Существующие GPS-трекеры предоставляют API; водители будут использовать личные Android-телефоны; доступ к API таможенной системы будет предоставлен к декабрю.

## 6. Краткое описание технической архитектуры
- Веб-приложение React -> Express API -> PostgreSQL; Android-приложение (Kotlin) работает с тем же API.
- Координаты GPS запрашиваются у поставщика трекеров каждые 30 секунд для 220 грузовиков; слоя кэширования нет.
- Все бизнес-правила (назначение маршрутов, ценообразование) находятся в одном файле `dispatch.js` на 4000 строк, написанном Анаром, без модульных тестов и почти без комментариев.
- Ключ API карт встроен в исходный код Android-приложения и веб-клиента.
- Фотографии подтверждения доставки хранятся на локальном диске сервера приложения.
- Местоположение и номера телефонов водителей видны любому авторизованному диспетчеру; разграничения ролей нет.
- Мониторинг и оповещения не настроены.
